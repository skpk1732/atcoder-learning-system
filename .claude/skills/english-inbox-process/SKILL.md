# 英語Inboxの処理（Claude処理・Ollama/API不要）

`2_Areas/English/英語Inbox.md` の未処理項目を **Claude自身が** 意味づけ・英訳し、`2_Areas/English/語彙・イディオム集.md` へ**チェックボックス行**として追記する。Ollamaや外部APIは使わない（訳の質はClaudeで担保、追加費用なし）。

状態は2値のみ：チェックなし `- [ ]` = 未、チェックあり `- [x]` = 済。未の一覧は `未の表現一覧.md`（Dataview TASKクエリ）が自動表示する。

## 手順

1. **Inboxを読む**: `2_Areas/English/英語Inbox.md` を Read。`## 未処理` セクション内の2欄から項目を集める：
   - `### 知らない単語・表現` の下の `- xxx` / `-xxx` 行（英単語・フレーズ）
   - `### 英語で言いたいこと` の下の `- xxx` 行（日本語の言いたいこと）
   - 無視: 空の `-` 行、`### 書き方`/`### 追加例` 内やコードブロック内の行、`## メモ` 欄。
   - `#llm` タグ付き行はカテゴリ `LLM/AI`（タグは訳語から除く）。大文字小文字は区別しない。
   - 未処理が無ければ「未処理なし」と報告して終了。

2. **重複チェック**: `語彙・イディオム集.md` を Read し、既にチェックボックス行にある表現（`**表現**` 部分を小文字化して比較）はスキップ。スキップは報告する。

3. **Claudeが訳を生成**（各項目）:
   - 単語・表現: 意味(日本語40字以内)・自然な例文(英語18語以内)・使い方メモ(日本語60字以内)。
   - 言いたいこと: 自然な英語(18語以内)・代替表現1つ・ニュアンスのメモ。丁寧で再利用しやすい表現を優先。
   - カテゴリは `日常` / `LLM/AI` / `コミュニケーション` / `論文` から1つ。

4. **語彙集へ追記**（Editツールで直接。Pythonスクリプトは使わない＝.tmpクラッシュ回避）:
   - 単語・表現 → `## Inbox Auto` の行リスト末尾に1行追加:
     `- [ ] **表現**｜意味｜例: 例文｜カテゴリ｜メモ`
   - 言いたいこと → `## 言いたいこと` の行リスト末尾に1行追加:
     `- [ ] **言いたいこと**｜英: 自然な英語｜別: 代替表現｜カテゴリ｜メモ`
   - 区切りは全角 `｜`。メモが無ければ末尾の `｜メモ` ごと省略。見出しが無ければ見出しごと作る。
   - チェックは必ず `- [ ]`（未）。意味やニュアンスが怪しい場合はメモに「要確認」と書く（チェック状態は変えない）。
   - Editは該当セクションの末尾付近だけを対象にする。ノート全体や大きなセクションを丸ごと置換しない。

5. **Inboxから処理済み行を削除**: `英語Inbox.md` の該当行を Edit で消し、欄には空の `-` を1つ残す。

6. **報告**: 何を追記し、何を重複スキップしたかを簡潔に。

## 方針
- 訳・意味・例文はClaudeが作る（Ollama・OpenAIは呼ばない。旧 `2_Areas/English/tools/` 系スクリプトは使わない）。
- 常駐監視はしない。スペルミスは正規化し、元入力をメモに残す。English関連ノート以外には触れない。
- `未の表現一覧.md` はDataviewクエリだけのノート。このスキルでは編集しない。
- Editが失敗したら、同じold_stringで再試行しない。対象ファイルをReadし直し、より短いold_stringでやり直す。
